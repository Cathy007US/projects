Quality IQC Inspection Standards Library质量 IQC 标准检验规范库

The Quality IQC Inspection Standards Knowledge Base is designed for PV module factories. It connects standard publishing, on-site reference, revision replacement, and audit tracing, forming a quality loop that starts with inspection standards. It centrally manages multiple document types for major materials such as solar cells, glass, encapsulants, frames, junction boxes, ribbons, busbars, EVA/EPE, and sealants, including SIPs, SOPs, drawings, and various forms. Highlights: Bilingual management: Chinese and English documents under the same standard number have independent files and revisions. Online preview: Word / Excel / PDF files can be previewed online, embedded images are restored, and original files can be downloaded. 质量 IQC 检验标准知识库面向光伏组件工厂，打通标准发布、现场查阅、版本替换和审计追溯，形成以检验标准为起点的质量闭环。可以集中管理多种文档，大物料如：电池片、玻璃、胶膜、边框、接线盒、焊带、汇流条、EVA/EPE、密封胶等物料的SIP,SOP；Drawing，各种Form。 亮点： 双语管理，同一标准编号下中英文文档独立文件、独立修订； Word / Excel / PDF 在线预览，内嵌图片还原，原文件可下载；

  • Frontend: Vite 5, React 18, TypeScript, TailwindCSS 3, React Router v6, lucide-react 前端：Vite 5、React 18、TypeScript、TailwindCSS 3、React Router v6、lucide-react
  • Backend: Python 3.11, FastAPI, Uvicorn, SQLAlchemy 2, Pydantic v2, python-docx, openpyxl, pypdf, PyJWT, bcrypt 后端：Python 3.11、FastAPI、Uvicorn、SQLAlchemy 2、Pydantic v2、python-docx、openpyxl、pypdf、PyJWT、bcrypt
  • Database: PostgreSQL 16, JSONB, psycopg, SQLAlchemy 2 数据库：PostgreSQL 16、iqc_insp、JSONB、psycopg、SQLAlchemy 2

Bookhealth体检预约

This health checkup appointment app connects online and offline services to build an O2O health checkup platform, providing users with a closed-loop health management journey that starts with a checkup. It includes Book an Appointment (select an institution, choose a package, fill in appointment details, add items, and pay), My Reports (view the report summary, view all test items, download the report, and consult a doctor), and My Appointments (cancel an appointment, reschedule, add items, snap up promotional packages, and more). Highlights: Book freely across multiple checkup institutions and a wide range of packages. Add checkup items on top of a base package. View reports online, compare historical checkup data, and receive online report interpretation from general practitioners. 体检预约APP体检该项目是从线上到线下，着力打造体检O2O平台；为用户提供以体检为起点的健康管理闭环。设计了我要预约（选机构、选套餐、填写预约信息、加项、支付）、我的报告（查看报告综述、查看全部项目、下载报告、咨询医生）、我的预约（取消预约、修改时间、加项抢购等） 亮点： • 多家体检机构、多种体检套餐随心预约； • 主套餐基础上，自主增加体检项目； • 在线查阅体检报告，历史体检数据交叉比对。全科医生线上为你解读报告;

  • Frontend: React 18 + TypeScript + Vite + TailwindCSS + React Router 前端：React 18 + TypeScript + Vite + TailwindCSS + React Router
  • Backend: Node.js + Express + TypeScript + Socket.IO + JWT + zod + multer 后端：Node.js + Express + TypeScript + Socket.IO + JWT + zod + multer

Charity Bills公益账单

A charity platform that makes hardship visible, lets the world see more love, and turns help into action. Supports bills and non-cash needs such as moving, consulting, and food. Core: • Publish, edit, close bills by month/year; • Share bills into a pool; others click "Help Them"; • Tabs: My Bills, Shared Bills, Helped; • Non-cash needs like moving, consulting, food; • Status: Pending / Helped / Unshared; • Profile shows monthly and yearly totals of shared/helped count, amount, category. Stack: React + Vite + TypeScript + Tailwind; REST API; PostgreSQL / MySQL; JWT; Stripe, PayPal; Docker + Nginx. 一个让困难被看见、让世界看到更多的爱、让帮助可落地的公益平台。支持账单与非现金需求，如搬家、咨询、食物等非现金支持。 核心功能： • 按月/年发布、编辑、关闭个人账单； • 账单共享后进入共享池，他人可点击「帮助 Ta」； • 共享菜单分「我的账单」「共享账单」「已帮助」； • 支持搬家、咨询、食物等非现金需求的发布与响应； • 状态流转：待帮 / 已帮 / 取消共享； • 我的页面展示本月与本年累计的共享/已帮数量、金额、类别。 技术栈：React + Vite + TypeScript + Tailwind；REST API；PostgreSQL / MySQL；JWT；Stripe、PayPal；Docker + Nginx。

My Journal我的日记本

A voice-first journaling tool that auto-generates summaries and a year-end autobiography. Core: • One-tap voice recording, speech-to-text, archived by date + title, to-do/done tagging; • Auto weekly, monthly, mid-year, year-end summaries; • Year-end compilation into an exportable autobiography; • Search by date, title, keyword; completion stats; • Rule-based facts + LLM wording to avoid fabrication. Stack: React + Vite + TS + Tailwind; MediaRecorder; ASR; REST API; PostgreSQL/MySQL; Docker + Nginx; HTTPS + JWT. 语音优先的个人记录工具，自动生成总结与年终自传书。 核心功能： • 一键语音记录，转文字后按日期+标题归档，标记待办/已完成； • 自动生成周报、月报、年中、年终总结； • 年终汇总为可导出个人自传书； • 按日期、标题、关键词检索，统计完成率； • 规则提取事实 + LLM 组织语言，避免编造。 技术栈：React + Vite + TS + Tailwind；MediaRecorder 录音；ASR 转写；REST API；PostgreSQL/MySQL；Docker + Nginx；HTTPS + JWT。
